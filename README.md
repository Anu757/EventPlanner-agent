# 🎉 AI Event Planner

An AI-powered Event Planner web application built using **Streamlit** and **Groq API** that generates detailed event plans and allows users to download them as a professionally formatted PDF.

---

## 🚀 Features

- 🤖 AI-generated event planning
- 📋 Structured output:
  - Overview
  - Budget 💰
  - Timeline ⏳
  - Vendors 🛍️
- 📄 Download event plan as a PDF
- 🖼️ Logo support in PDF
- 🎨 Clean and simple user interface

---

## 🛠️ Tech Stack

- **Frontend/UI:** Streamlit  
- **Backend:** Python  
- **AI Model:** Groq API (LLaMA models)  
- **PDF Generation:** ReportLab
